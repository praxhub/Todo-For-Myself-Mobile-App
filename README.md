# Todo For Myself Mobile App

Flutter implementation with:
- Task CRUD (home, form, detail) with due date, image, and voice note support.
- Image attachment via camera/gallery with compression and local storage.
- Voice notes with record/play/delete and 5 minute max duration.
- Daily journal entries by date with optional image.
- Monthly calendar highlighting task dates and date drilldown.
- Animated light/dark sun-moon toggle with theme persistence.
- Android home screen widget displaying today's task count.
